# Pages légales de Nookeon

Ce dépôt existe pour **une seule raison** : le dépôt de l'application est
privé, et GitHub Pages n'est pas gratuit sur un dépôt privé. App Store Connect
exige une URL de politique de confidentialité **publiquement accessible** pour
ouvrir un test externe sur TestFlight.

    https://captainhook1.github.io/nookeon-legal/

## ⚠️ La source de vérité n'est PAS ici

`index.html` est une **copie** de `site/confidentialite.html` du dépôt Nookeon.
Toute modification se fait là-bas, puis se recopie ici. Corriger directement ce
fichier créerait deux versions d'un document juridique, et c'est exactement le
genre de divergence qu'on ne remarque qu'au mauvais moment.

## Ce qui reste à remplir

Trois blancs, surlignés dans la page pour qu'on ne puisse pas les manquer :
`TON-NOM-COMPLET`, `TON-ADRESSE-POSTALE`, `CONTACT@TON-DOMAINE`. Le RGPD
(art. 13) exige l'identité et le contact du responsable de traitement.

Et une phrase absente exprès, au chapitre du modèle d'IA : voir le commentaire
HTML à cet endroit.

## Le jour où le vrai domaine existe

Ces pages retournent sur le site (`/confidentialite`), l'URL est changée dans
App Store Connect, et ce dépôt peut disparaître.
